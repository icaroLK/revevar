# Reve VAR

Instant-replay website for a sports field in Curitiba, Brazil. Cameras + a physical button capture a short clip around the moment a player presses it; this is the site where players find and download their clips.

**Status:** early build — Sprint 1 in progress (new public catalog site, mobile-first).

## What this is

A freelance rebuild of an existing (very basic) replay site: no filters, no structure, fully public. This project replaces it with a clean, mobile-first catalog and player, built so accounts and other features can be added later without a rewrite.
