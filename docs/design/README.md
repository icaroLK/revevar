# Design reference (approved layout)

Approved mockups exported from the Claude Design canvas. They need the canvas runtime to render, so **opening them locally won't show the design**. Use them two ways:
1. **Read the markup** for exact values (colors, sizes, spacing, copy, structure). They use inline styles, so every value is visible.
2. **Screenshots** for the look: export each screen from the canvas (Export, as PNG) into `docs/design/screens/` and point Claude Code at them.

They are references, not code to copy.

- Home: Início (desktop) · MobileHome: Início (mobile)
- Replays / MobileReplays: catálogo com filtros
- Replay / MobileReplay: página do replay
- ComoFunciona / MobileComoFunciona
- Clubes / MobileClubes: Para clubes
- MobileMenu: menu aberto no celular
- MobilePrototype: protótipo navegável do celular (comportamento)
- logo-white.png: logo para fundo escuro (temporário; pedir SVG ao cliente)

The mockups reference the logo through a canvas-only URL (/_blob/...). In the app use logo-white.png (until the client sends an SVG).
